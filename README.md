# CoChoice pour les mutuelles étudiantes

Landing page séparée, destinée aux mutuelles étudiantes (prévention, partenariats écoles).
Objectif unique : obtenir une demande de rendez-vous en vue d'un pilote.

Vite 7 + Tailwind CSS v4. Consigne complète : voir `CLAUDE.md`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # sortie dans dist/
```
